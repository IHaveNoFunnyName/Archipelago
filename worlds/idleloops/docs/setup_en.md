# Idle Loops Randomizer Setup Guide

## Required Software

- [The game](https://lloyd-delacroix.github.io/omsi-loops/)
- Some sort of userscript extension like [Tampermonkey](https://www.tampermonkey.net/) to install the mod

## Installation
- If you have a Tampermonkey-like extension, clicking [this link](https://ihavenofunnyname.github.io/IdleLoopsAP/idle-loops-ap.user.js) should prompt you to install the mod.
